CREO 디지털 브랜드북 - Netlify 무료 업로드용

업로드 방법
1. https://app.netlify.com/ 에 접속하고 무료 계정으로 로그인합니다.
2. Add new site → Deploy manually 를 선택합니다.
3. 이 ZIP 파일의 압축을 풉니다.
4. 압축을 푼 'netlify_creo_brandbook' 폴더 전체를 드래그해서 업로드합니다.
5. 배포가 끝나면 xxxx.netlify.app 형태의 공개 주소가 생성됩니다.
6. 그 주소를 카카오톡, 문자, 네이버 블로그 등에 전달하면 됩니다.

주의
- index.html이 폴더의 최상위에 있어야 합니다.
- pages, videos, assets 폴더를 삭제하거나 이름을 바꾸면 안 됩니다.
